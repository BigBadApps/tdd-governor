# G1 CI Mirror Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pull request cannot merge with a diff the local gates would have blocked, even when the author used `--no-verify`.

**Architecture:** A new `governor gate ci [--base <ref>]` command runs `green`, `diff-audit` and `mutation` against `base..HEAD`, skips `red-before-green` (needs the local ledger, gap G3) with a printed line, and ignores `GOVERNOR_OVERRIDE`. A workflow template fetches the governor with a read-only secret and runs the command. The mutation logic is extracted from `gatePush` so push and CI share one code path.

**Tech Stack:** Stages 1–3 (TypeScript, Node ≥ 22, vitest 3.2, Stryker 10), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-18-g1-ci-mirror-design.md` (parent: `docs/superpowers/specs/2026-09-18-tdd-governor-design.md`)

**Prerequisite:** Stage 3 and the G1 spec merged (both done).

## Global Constraints

- Every commit ends with `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`.
- The governor gates its own commits (pre-commit hook). Test-first: write the test, add a stub so the test fails on an **assertion** (not a missing export or `TypeError`, gap G6), run `npx vitest run <file>` so the reporter records the red, then implement. Record the first-red output.
- Never `git rebase --exec` or otherwise re-run hooks across commits that predate `c73fa64`. Use `filter-branch` for message rewrites.
- Do not `git push`, open PRs, or delete branches without the user's approval. `git branch -d/-D` is blocked by the `dcg` hook: give the user the command.
- Exit codes: 0 pass, 1 blocked, 2 usage or environment error. A shallow checkout or missing base is exit 2, never a pass.
- `GOVERNOR_OVERRIDE` is ignored in CI. `red-before-green` is skipped in CI with the exact printed line `red-before-green: skipped in CI (needs local ledger, G3)`.
- Final gate for each code task: `npx tsc --noEmit && npm test && npm run build` exit 0.
- Work on branch `feat/g1-ci-mirror`, created from `main` in a worktree via `superpowers:using-git-worktrees`. The hooks embed the absolute path of the `dist/cli.js` they were installed from; before removing any worktree, re-run `node dist/cli.js install` from the main checkout.

```ts
export function ciBase(root: string, flag: string | undefined, env: NodeJS.ProcessEnv = process.env): string {
```

```ts
  findings: [{ file: '.governor/config.json', message: 'warning: mutation gate disabled in .governor/config.json' }],

function mutationGate(root: string, config: GovernorConfig, diff: FileDiff[]): GateResult {
  const isSource = picomatch(config.sourceGlobs);
  const isTest = picomatch(config.testGlobs);
  const changed = changedLines(diff, (p) => isSource(p) && !isTest(p));
  if (changed.size === 0) return { gate: 'mutation', status: 'PASS', findings: [] };

  const run = config.adapter === 'vitest'
    ? runStryker(root, [...changed.keys()], config.mutation.timeoutMs)
    : { ok: false as const, error: `mutation for adapter '${config.adapter}' is not implemented yet` };
  return run.ok
    ? mutation({ mutants: run.mutants, changed })
    : { gate: 'mutation', status: 'GATE_UNAVAILABLE', findings: [{ file: '(mutation)', message: run.error }] };
}
```

```ts
function gateCi(root: string, baseFlag: string | undefined): number {
  const loaded = loadConfig(root);
  if (!loaded.ok) {
    console.log(formatResults([{ gate: 'green', status: 'GATE_UNAVAILABLE', findings: [{ file: '.governor/config.json', message: loaded.error }] }]));
```

```yaml
# Setup:
#   1. Add the repo secret GOVERNOR_READ_TOKEN: a fine-grained PAT with read-only
#      "Contents" access to BigBadApps/tdd-governor.
#   2. Replace GOVERNOR_SHA below with a tdd-governor commit that includes `gate ci`.

name: governor
on:
  pull_request:
jobs:
  gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - name: Fetch and build the governor
        env:
          GOVERNOR_READ_TOKEN: ${{ secrets.GOVERNOR_READ_TOKEN }}
        run: |
          git clone --quiet "https://x-access-token:${GOVERNOR_READ_TOKEN}@github.com/BigBadApps/tdd-governor.git" "$RUNNER_TEMP/governor"
          git -C "$RUNNER_TEMP/governor" checkout --quiet GOVERNOR_SHA
          npm ci --prefix "$RUNNER_TEMP/governor"
          npm run build --prefix "$RUNNER_TEMP/governor"
      - run: npm ci
      - name: Gate
        env:
          GOVERNOR_HOME: ${{ runner.temp }}/governor
        run: node "$GOVERNOR_HOME/dist/cli.js" gate ci
```
